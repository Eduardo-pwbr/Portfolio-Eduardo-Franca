# Portfólio — Eduardo França

Portfólio profissional desenvolvido com React + TypeScript + Vite.

## Tecnologias

- React
- TypeScript
- Vite
- Lucide React
- CSS responsivo

## Executar localmente

```bash
npm install
npm run dev
```

Depois acesse o endereço mostrado pelo Vite.

## Antes de publicar

Edite em `src/App.tsx`:
- e-mail de contato
- links dos projetos
- descrições
- experiências
- tecnologias

## Deploy

O projeto pode ser publicado na Vercel usando o comando de build:

```bash
npm run build
```
